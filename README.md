# The very brief big picture: 

There is widespread interest among evolutionary geneticists in making predictions about parallel (//) evolution. Theory available so far envisions both mutational and selection heterogeneity across the genome and its consequences for expected patterns of parallel evolution. 

A central quantity of interest is the probability $P_i$ that a specific locus $i$ will contribute the next beneficial mutation to be fixed in an evolving population. If one considers a set of $L$ loci, one can use the $P_i$'s to predict, among other things, the probability of "gene reuse" as an operational measure of the degree of parallel evolution between 2 populations, or the distribution of counts of mutations per gene across a larger set of populations.
